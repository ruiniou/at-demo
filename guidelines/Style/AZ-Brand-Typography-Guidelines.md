# Typography

## 1. System Fonts —— 日常办公（Microsoft / macOS）

用于 Microsoft 365 全套应用（PowerPoint / Word / Email 等），所有电脑预装，接收方显示效果一致，且已预设在AZ模板中。

| 用途 | 字体 | 字重 |
| --- | --- | --- |
| Headings, subheadings and quotes | **Calisto** | Regular / Bold |
| Body text | **Calibri** | Light / Regular / Bold |

## 4. Color Highlight

### 4.1 基本原则

- 色彩高亮体现"如何强调科学内容"（reflect how we emphasise science）
- **仅可用 Mulberry、Magenta 或 Gold** 做文字高亮
- 只能使用核心色板（Core）与中性色（Neutrals），**禁止使用次要色（Secondary：Purple/Navy/Light Blue/Lime Green）**
- 需保证对比度与可读性（Contrast and readability）

### 4.2 高亮场景的Accessibility组合

| 等级 | 组合 |
| --- | --- |
| **AAA** | Dark Mulberry 背景 + **Gold** 高亮文字 |
| **AA** | Mulberry / Graphite / White / Light Platinum 背景 + **Gold** 高亮文字 |
