# Figure 渲染预览 — Copilot 入口卡片 & Preview 悬浮窗口

适用范围：Atlas · Figure 模块 · AI Copilot

---

## 一、背景

Blueprint 生成后，用户目前只能通过 Shell（模板结构）和 Code Copilot（AI 推理信息）判断 Figure 是否符合预期，缺少一个"所见即所得"的直观校验手段。本功能在此基础上补充：

1. **Copilot 内的渲染结果入口卡片**（Image Render Tool Call）
2. **Preview 悬浮窗口**（承载大图查看 + 历史版本浏览）

两者共用同一套版本数据，卡片是入口，悬浮窗口是查看容器。

---

## 二、组件一：Image Render Tool Call 卡片

位置：Copilot 对话流内，复用现有 Tool Call 组件结构。但无折叠

### 2.1 顶层状态（三态并列，非互为子状态）

| 状态  | 标题文案 | 内容区 |
|---|---|---|---|
| **Generating**（生成中） | Loading 态文案（如 "Generating preview..."） | 无缩略图 |
| **Complete**（生成完成）  | 版本号本身（如 "V1.3"） | 缩略图，占满卡片宽度 |
| **Failed**（生成失败）  | 失败文案 + Retry 文字按钮，复用 Code 生成失败态样式 | 无缩略图 |

> Failed 态复用已有 Code 失败态的处理方式，不新设计一套。

### 2.2 Complete 态的两个独立状态维度

**卡片级（作用于整个卡片容器，折叠/展开都生效）**

| 状态 | 表现 |
|---|---|
| Default | 无特殊标记 |
| Focus | 卡片描边高亮，表示"当前 Preview 悬浮窗口打开的正是这一版"。作用对象是整张卡片，


### 2.4 版本标识 Badge

| 版本 | Badge 内容 |
|---|---|
| 最新版本 | 【Latest】 |
| 非最新版本 | 相对时间戳，如 "3 min ago" |

> 该规则同时适用于卡片标题栏，以及 Preview 悬浮窗口内的缩略图列表（见 4.3），两处保持一致，不需要用户在两个地方分别判断"哪个是最新"。

---

## 三、组件二：Preview 悬浮窗口

### 3.1 基本性质

非 Modal，无遮罩背景。窗口悬浮在画布上方，Shell/Code 切换控件、画布、侧边栏、Copilot 面板全程保持可交互——核心使用场景就是"边看 Shell 边看渲染图对比"，因此背景不能被锁定。

### 3.2 触发方式

点击 Copilot 卡片内的缩略图（2.2）→ 打开悬浮窗口，定位到该版本。

### 3.3 容器规格

| 项目 | 规则 |
|---|---|
| 拖拽 | 窗口头部（版本 Badge 所在行）可拖拽移动位置 |
| 缩放 | 右下角拖拽，宽高联动缩放，无独立的图片 +/− 缩放控件——图片跟随窗口尺寸自适应 |
| 默认尺寸 | 宽度 ≥ Copilot 缩略图宽度的 1.6 倍，约 480×380px 起，具体数值按 Figma 实际缩略图比例核准 |
| 默认位置 | 见 3.4，用户手动拖动后不再回退默认位置，仅本次未拖动过时生效 |

### 3.4 默认位置规则

Shell 在画布中的位置固定（不可被用户左右互换），因此三种画布状态的锚点坐标可以直接写死，不需要运行时判断：

| 画布状态 | Shell 位置 | 窗口默认锚定区域 |
|---|---|---|
| Shell 单开（占满画布） | 全屏 | 画布右侧，靠近 Copilot 面板边界 |
| 左右 split | 固定在左 | 右半区（Code 一侧） |
| 上下 split | 固定在上 | 下半区（Code 一侧） |

统一逻辑：**默认位置永远落在"非 Shell"区域**，保证打开即可与 Shell 对比，不需要用户先手动挪开窗口。

### 3.5 内容区布局

**左侧（弹性宽度，占主要空间）：大图展示区**
- 图片居中，等比缩放铺满可用空间
- 底部固定说明文案，10px，单行显示（默认窗口宽度下不换行），文案需明确指出"预览图与 Code 最终跑出的结果会有差异"，不用模糊表达

**右侧（固定宽度 ~130px）：缩略图列表**
- 无标题文字（不写"Version History"之类的标签），直接是缩略图堆叠
- **单版本**：不显示 Carousel，右侧列表区域不出现
- **多版本**：显示 Carousel，按时间倒序排列（最新在上）
- 每张缩略图：
  - 最新版 → 【Latest】Badge
  - 非最新版 → 仅显示版本号（如 "V1.2"），不叠加其他信息
- **失败版本不进入该列表**——失败态只存在于 Copilot 卡片（2.1），悬浮窗口内没有对应缩略图入口

### 3.6 点击切换

点击右侧任意缩略图 → 左侧大图切换为该版本，选中态跟随移动，不关闭 / 重开窗口。

---

## 四、失败态处理原则

两类错误性质不同，处理方式也不同，**均为原地状态，不额外弹出新 Block**：

| 错误类型 | 触发场景 | 处理方式 |
|---|---|---|
| 生成失败 | Code 语法错误 / 数据未就绪 / 模型 API 不可用 | Copilot 卡片原地进入 Failed 态（2.1），不产生可点击缩略图，因此不会出现在悬浮窗口里 |
| 图片加载失败 | 悬浮窗口已打开，图片本身生成成功但展示时加载失败 | 悬浮窗口大图区域原地替换为"加载失败 + 重试"提示，不新开 Block |

## 六、附录：状态关系速查

- Copilot 卡片 Focus 态 ↔ 悬浮窗口当前显示版本：**联动**，窗口切换到哪一版，对应卡片即高亮
- Copilot 卡片折叠 / 展开：**不影响** Focus 态可见性（Focus 挂在卡片容器，非缩略图）
- Copilot 卡片 Latest / 时间戳 Badge ↔ 悬浮窗口缩略图 Badge：**同一套数据，两处展示规则一致**
