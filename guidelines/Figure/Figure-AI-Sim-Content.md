## AI Copilot 推理消息：完整重写（替换现有内容，不是追加）

**流程背景**：用户上传 Shell 文件后，AI 完成解析、结构理解、SAS Code 生成——这个过程在用户打开页面之前已经跑完。用户打开 Figure 时，看到的是 **Shell Preview + AI Copilot 面板同时展开**，Copilot 里一次性展示这一整段推理过程（不需要逐条播放/打字机效果，直接完整展示）。

**内容要求**：
- 完整覆盖从"解析 Shell"到"生成 SAS Code"的推理链路，但**篇幅要精简**，不要写成完整的分析报告
- 中间对应"AI 推断/来源冲突"的部分，需要有明显的高亮处理（不是和其他文字一样的纯文本），提示用户这是需要留意的点
- **结尾必须是一个规整的 "To be Reviewed" 区块**，不是自然语言收尾，格式类似：
  ```
  To be Reviewed
  · [具体字段/问题名称]（可点击，链接跳转到 Metadata 面板对应字段）
  · [具体字段/问题名称]（可点击，链接跳转到 Metadata 面板对应字段）
  ```
  这个区块**不能省略、不能用"生成完成"这类收尾语气替代**——目的是明确引导用户去 Metadata 面板做 Full-scope Review，不能让用户误以为看完 Copilot 的推理就等于审核完毕了

**复用与新增**：
- 复用 Copilot 面板已有的消息气泡样式和行内引用跳转交互（点击文字定位到 Metadata 对应字段/Component）
- "To be Reviewed" 这个区块本身是新增的格式化结构（列表 + 链接），不是普通消息气泡，具体视觉呈现由截图和 Design System 决定，但结构上必须是清晰的列表格式，不能写成一段话夹在文字里
