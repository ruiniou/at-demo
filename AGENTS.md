# Repository Agent Instructions

Before working on a task in this repository, read `.agents/AGENTS.md` and follow its skill-dispatch rules.

Repository-specific skills are stored in `.agents/skills/`. Read the matching `SKILL.md` completely before applying a skill. Feature design, requirement analysis, user-flow design, and rule documentation also use `taimei-trials-ux/SKILL.md` as directed by `.agents/AGENTS.md`.

These instructions apply to the repository root and all descendant directories unless a more specific `AGENTS.md` exists deeper in the tree.
